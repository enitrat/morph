# Product

## Platform

web

## Users

Frontend designers and design engineers iterating on a running interface. Installation requires someone comfortable with a React development environment.

## Product Purpose

Morph lets a person point at an element in a running React app, describe a change, compare generated alternatives in context, refine the result, and keep a chosen version. The human directs the exploration and makes the final choice.

## Operating Context

Morph is a development-only overlay. It uses the Claude CLI and git worktrees to create variants of real code. It supports React 19 apps using Next.js App Router or Vite. It works on the user's own components and design tokens.

## Capabilities and Constraints

Variants can be compared on the live page. Users can fine-tune design tokens, Tailwind utilities, and component props. Morph writes to the working tree while the development server runs. See README.md for setup and requirements.

## Brand Commitments

The product is named Morph. The user has requested a bold landing page informed by their saved shader, landing-page, and design-engineering references in second-brain.
